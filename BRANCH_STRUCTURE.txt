Key Points:
-----------
1. The 'main' branch preserves all user commits and history
2. The 'master' branch now mirrors the upstream repository
3. This allows for easier tracking of upstream changes
4. Users can merge upstream changes into master, then merge master into main


To Complete Migration:
-----------------------
Run: ./migrate-branches.sh

This will push both branches to GitHub:
- main branch → new branch on GitHub
- master branch → force push to reset to upstream
